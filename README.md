# Software Hub | Osmair Pereira

Vitrine interativa de software e portfólio colaborativo.  
Central de apresentação de projetos próprios e catálogo distribuído para desenvolvedores parceiros.

---

## Sobre o Projeto

O Software Hub foi concebido não apenas como um portfólio tradicional de currículo, mas como uma central de soluções de software e vitrine compartilhada. 

O projeto une uma interface com tema escuro (dark mode), inspirada em arquiteturas modernas e compactas de exibição (como mxb.dev e ian.dunkerley.dev), a um sistema interativo de cartões e modais informativos (inspirado em jgbpedro.github.io).

### Principais Pilares:
* **Meus Projetos:** Espaço central dedicado às minhas soluções próprias, automações e aplicações desktop/web.
* **Hub de Parceiros:** Aba dedicada para dar visibilidade a projetos e ferramentas desenvolvidas por programadores parceiros e membros da comunidade.
* **Navegação Ágil e Modais:** Informações técnicas organizadas com visão rápida em cards e detalhamento sob demanda (tecnologias, problemas resolvidos, notas de versão e ficha técnica).
* **Filtros e Busca em Tempo Real:** Pesquisa dinâmica por nome, categoria técnica e tecnologia utilizada.

## Tecnologias Utilizadas no Hub

A plataforma foi construída com foco em performance, leveza e código limpo, sem dependência de frameworks pesados:

* **HTML5 Semântico:** Estrutura acessível com metadados e atributos ARIA.
* **CSS3 Moderno:** Paleta de cores com tema escuro (Aurora/Dark), variáveis CSS nativas, Flexbox e CSS Grid responsivo.
* **JavaScript (ES6+ Vanilla):** Controle de estado centralizado, manipulação dinâmica de DOM para renderização de cards, filtragem instantânea e controle de acessibilidade nos modais.
* **Ícones e Tipografia:** Lucide Icons, fontes Instrument Sans, Plus Jakarta Sans e Geist Mono.

## Como Executar Localmente

### Pré-requisitos
* Um navegador moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).
* Editor de código (recomendado: VS Code).
* Extensão recomendada no VS Code: Live Server.

### Passo a Passo:
1. Clone o repositório ou baixe os arquivos para a pasta do projeto.
2. Abra a pasta `PortifolioOsmair` no VS Code.
3. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.  
   *A página abrirá automaticamente no seu navegador padrão.*
